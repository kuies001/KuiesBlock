# KuiesBlock v0.4.2 — 正式版本（Stable）

> 這是正式版本，不是測試版。從本檔開頭到「發布流程備註」之前的內容，就是 GitHub Release 發布頁的正文。

v0.4.2 重新整理廣告攔截強度與過濾來源：原本的寬鬆／標準／嚴格三種模式保留，新增「自訂」，並可在裝置上選擇八個預設來源。三種預設模式仍只使用各自對應的 HaGeZi 主清單；只有自訂模式會使用你勾選的來源組合。

## 這個版本新增什麼

1. **四種廣告攔截模式**：寬鬆、標準（推薦）、嚴格、自訂。
   - 寬鬆固定使用 HaGeZi Multi LIGHT。
   - 標準固定使用 HaGeZi Multi NORMAL。
   - 嚴格固定使用 HaGeZi Multi PRO++。
   - 三種預設模式不會疊加其他來源，避免不同清單互相影響。
2. **自訂模式與八個預設來源**：HaGeZi Multi LIGHT／NORMAL／PRO++、HaGeZi TIF (Mini)、AdGuard DNS Filter、OISD、HaGeZi NSFW、HaGeZi Social。
   - 三種 HaGeZi Multi 主清單只能擇一，其他來源可以同時啟用。
   - 至少要保留一個來源；最後一個來源不能被取消。
   - 來源列會顯示名稱、用途、維護者與授權。
3. **更誠實的過濾器管理**：顯示目前模式實際有效的來源、各來源下載狀態、目前生效規則數與最近更新結果。
   - 清單尚未下載完成時會顯示真實狀態，不會假裝已經生效。
   - 「立即更新」與自動更新只處理目前模式需要的來源。
4. **切換模式不刪除既有資料**：切換模式會保留已下載的清單與自訂選擇；切換後立即重建本機規則。
5. **舊版設定相容**：
   - 原本沒有額外自訂訂閱的使用者，會保留原本的寬鬆／標準／嚴格模式。
   - 原本有啟用的額外自訂訂閱，會一次性遷移到自訂模式，並保留原本的主清單層級與訂閱資料。
   - 舊的手動允許／封鎖規則仍保存在裝置上，但設定頁已沒有編輯入口，且不再進入本機規則快照。
   - 舊的自訂訂閱資料也會保留，但本版沒有 URL／名稱編輯入口。

## 這個版本的限制（請務必先看）

1. **HaGeZi TIF 使用官方 Mini 版本。** 完整 TIF 清單約 39 MB，超過目前的下載與解析上限，因此本版使用官方的 `tif.mini.txt`。
2. **來源由第三方維護。** 清單格式或網址可能變動；下載失敗時會保留上一次成功清單，不會把目前可用的規則刪掉。
3. **舊手動允許／封鎖規則不再生效。** 資料仍保留，但本版沒有編輯入口；這是為了避免移除介面後仍有看不到的規則在作用。
4. **舊自訂訂閱只在自訂模式參與。** 三種預設模式不會使用它們，且本版沒有新增或編輯自訂訂閱的介面。
5. **私人 DNS 設為「指定主機名稱」時，本機規則無法攔截。** 系統會自己把查詢送到指定主機，不經過 KuiesBlock。
6. **「防護已啟用」不等於「本機規則正在生效」。** 清單尚未下載完成，或系統私人 DNS 接管解析時，連線正常但規則沒有作用；畫面會顯示實際狀態。
7. **無法與其他一般的 Android VPN 同時運作。** Android 一次只允許一條 VPN。
8. **App 自帶的 DoH，或其他繞過系統 DNS 的流量，不保證能被攔截。**
9. **不宣稱能完整阻擋 YouTube 廣告。** DNS 過濾無法涵蓋所有廣告請求。
10. **自動更新與開機自動恢復都是盡力而為。** Android 的省電機制可能延後背景工作；開機恢復也可能因 App 曾被強制停止或系統略過廣播而失效。
11. **「檢查 App 更新」只會開啟 GitHub Release 頁面**，不會自動下載或安裝 APK。
12. **只攔截 IPv4 的 UDP DNS。** 不支援 DNS-over-TCP，也不攔截 IPv6 的 DNS。

## 安裝資訊

- 套件名稱：`tw.kuies.block`
- 版本：`versionName 0.4.2`／`versionCode 8`
- 最低需求：Android 9（API 28）；目標 API 37
- 與 v0.4.1 使用相同的正式簽章，可直接覆蓋升級；設定與已下載的清單會保留
- 發布檔案：`KuiesBlock-v0.4.2.apk`，校驗檔 `KuiesBlock-v0.4.2.sha256`

## 驗證方式

- 建置：`:app:assembleDebug`、`:app:assembleRelease`（含 R8 與 lintVital）成功，Release 以既有正式簽章簽署。
- 單元測試：603 個測試（69 個測試類別）、0 失敗、1 略過（略過者需要環境變數才會執行）。
- 實機：四種模式與八個來源的設定頁可讀；NORMAL、AdGuard、OISD、TIF、NSFW 五個來源實際下載成功；多來源組合顯示 583,572 條生效規則，「立即更新」成功；標準模式的 filter 情境 PASS 9/0，本機封鎖計數確實增加。
- 尚未實機驗證：舊版「已啟用自訂訂閱」的升級遷移、多來源的自動背景更新，以及 release 簽章 APK 覆蓋安裝。這些項目由單元測試或簽章檢查覆蓋，但不列為實機 PASS。
