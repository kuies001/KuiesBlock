# KuiesBlock v0.4.43 — 正式版本（Stable）

> 這是正式版本，不是測試版。從本檔開頭到「發布流程備註」之前的內容，就是 GitHub Release 發布頁的正文。

v0.4.43 精簡設定頁：主題、廣告攔截強度與過濾器自動更新改為一致的摺疊選單；同時把 App 內更新改為 Android `PackageInstaller` Session，避免 v0.4.42 實機出現的第三方 APK 安裝器選擇視窗。

## 這個版本新增什麼

1. **設定頁三個摺疊選單**
   - 主題：預設收合，顯示目前模式；展開為跟隨系統、深色、淺色，選擇後立即套用、儲存並收合。
   - 廣告攔截強度：預設收合，顯示「寬鬆／標準／嚴格／自訂」；選擇前三個固定模式後自動收合。
   - 過濾器自動更新：位於「過濾器管理」內，收合顯示「已開啟 · 每 8／24 小時」或「已關閉」；展開才顯示開關與週期。
2. **自訂模式維持原本操作**
   - 選擇「自訂」後不會立刻收合，會留在展開區繼續勾選來源。
   - 保留 HaGeZi Multi 主清單單選、其他來源複選、至少一個有效來源與既有資料。
3. **自動更新週期保留**
   - 關閉再開啟自動更新時，仍使用原本選擇的 8／24 小時週期。
   - WorkManager 排程與實際更新機制沒有改變。
4. **改用 Android PackageInstaller Session**
   - 已驗證的 APK 直接寫入 `PackageInstaller` Session，由 Android 系統安裝器負責確認。
   - 移除 `FileProvider`、一般 APK `ACTION_VIEW` Intent 與 `update_file_paths.xml`，不再讓第三方 APK 安裝器出現在選擇清單。
   - 保留 SHA-256、套件名稱、版本與簽章驗證；未通過驗證的 APK 不會進入 Session。
   - 保留未知來源安裝授權流程；沒有 root、Accessibility、隱藏 API 或靜默安裝。
   - 未硬編碼 Samsung 或其他廠牌安裝器名稱。

## 這個版本的限制（請務必先看）

1. **本版沒有改變 DNS、VPN、過濾器下載與解析、WorkManager、個別 App 防護、私人 DNS 或開機自啟。**
2. **本輪沒有執行 Emulator、ADB 或實機測試。** 以下全部為 `INCONCLUSIVE`：
   - 三個摺疊選單的實際展開／收合、箭頭方向與點擊區域。
   - 主題立即生效、自動收合與重啟後保留。
   - 廣告攔截強度切換、自訂來源勾選與自動收合。
   - 自動更新開關、週期保留與 WorkManager 實際排程。
   - `PackageInstaller` 系統確認、未知來源授權、取消／失敗訊息。
   - 是否完全不再出現第三方 APK 安裝器選擇視窗。
   - 覆蓋安裝與既有資料保留。
3. **v0.4.42 與之前版本的所有已知限制繼續適用。**
