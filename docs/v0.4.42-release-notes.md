# KuiesBlock v0.4.42 — 正式版本（Stable）

> 這是正式版本，不是測試版。從本檔開頭到「發布流程備註」之前的內容，就是 GitHub Release 發布頁的正文。

v0.4.42 新增主題切換：KuiesBlock 可以跟隨 Android 系統、固定淺色，或固定深色。切換會立即套用到所有畫面、對話框與系統列圖示，不需要重新開啟 App。

## 這個版本新增什麼

1. **三種主題模式**
   - 跟隨系統：依 Android 目前的深色／淺色設定自動切換，系統變更時同步更新。
   - 淺色：固定使用 KuiesBlock 淺色配色。
   - 深色：固定使用 KuiesBlock 深色配色。
2. **設定頁最上方新增「主題」區塊**
   - 位於「廣告攔截強度」之前。
   - 三個單選項目，一次只能選一個。
   - 沒有額外說明、預覽或動畫。
3. **立即生效且會保留**
   - 切換後立即套用到首頁、設定頁、App 個別設定、對話框與更新下載畫面。
   - 狀態列與導覽列圖示明暗會同步調整。
   - 選擇會寫入既有私有設定，App 重新啟動後仍保留。
4. **相容既有使用者**
   - 首次安裝或原本沒有主題設定的使用者，預設「跟隨系統」。
   - 不修改其他偏好設定，也不清除任何使用者資料。

## 這個版本的限制（請務必先看）

1. **本版只新增主題切換。** DNS、VPN、過濾器、個別 App 防護、私人 DNS、開機自啟與 App 內更新流程都沒有改變。
2. **主題屬於外觀變更。** 本輪未執行 Emulator 或 ADB 實機測試；三種主題的實際配色、系統切換同步、狀態列／導覽列對比、各頁與對話框一致性，以及重啟後保留，需由使用者實機確認。
3. **App 內更新流程的實機驗證另計。** v0.4.42 可作為 v0.4.41 App 內更新的正式版本候選；實際下載、未知來源授權與系統安裝器流程需在正式簽章 v0.4.41 裝置上確認。
4. **v0.4.41 與之前版本的所有已知限制繼續適用。**
