# KuiesBlock v0.4.1 — 正式版本（Stable）

> 這是正式版本，不是測試版。從本檔開頭到「發布流程備註」之前的內容，就是 GitHub Release 發布頁的正文。

v0.4.1 讓過濾清單自動保持最新，並補上「重新開機後自動恢復防護」與設定頁最下方的「檢查 App 更新」。

## 這個版本新增什麼

1. **過濾清單定期自動更新**：預設開啟、每 24 小時檢查一次，可以在設定頁改成每 8 小時。
   只更新**已經下載過**的清單，所以全新安裝在你選好攔截強度之前不會下載任何清單；
   更新失敗時仍然保留上一次成功的清單。關閉這個開關會取消週期工作，「立即更新」不受影響。
2. **開機自動恢復防護**：預設關閉，你自己打開之後，手機重新開機時會嘗試恢復 KuiesBlock 防護。
   沒有完成 VPN 授權、其他 App 佔用 VPN 位置、或無法確認 VPN 狀態時一律不動作；
   過程中不會跳出授權視窗、不會改動私人 DNS、也不會關閉其他 VPN。
3. **設定頁最下方的「檢查 App 更新」**：手動查詢 GitHub 上的最新正式版本，直接和你手機上的版本比較。
   查詢不需要帳號或金鑰；只有查到新版本才會顯示更新說明與「前往下載」，
   而且只會用瀏覽器開啟本專案的 GitHub Release 頁面，**不會自動下載或安裝**。

## 這個版本的限制（請務必先看）

1. **自動更新不保證準時。** Android 的省電機制（Doze／App Standby）可能讓背景的週期工作延後執行。
2. **開機自動恢復不保證每次都成功。** App 如果曾被強制停止、或從未開啟過，就收不到開機通知；
   系統也可能延後或略過這個動作。要在重新開機後更可靠地恢復，請在系統設定開啟 KuiesBlock 的
   「一律開啟的 VPN」。
3. **「檢查 App 更新」不會自動下載或安裝 APK**，只會開啟 GitHub Release 頁面。
4. **私人 DNS 設為「指定主機名稱」時，本機規則無法攔截。** 這種情況下系統會自己把查詢送到指定的主機，
   不經過 KuiesBlock，本機規則也就沒有作用。
5. **「防護已啟用」不等於「本機規則正在生效」。** 清單還沒下載完成，或系統私人 DNS 接管解析時，
   連線是正常的，但規則並沒有在作用；畫面會分別顯示實際狀態。
6. **無法與其他一般的 Android VPN 同時運作。** Android 一次只允許一條 VPN 連線，KuiesBlock 不能和別的
   VPN App 並存；偵測到其他 VPN 時只會顯示提示，不會自行把它關掉。
7. **App 自帶的 DoH，或其他繞過系統 DNS 的流量，不保證能被攔截**（例如自帶 DoH 的瀏覽器）。
8. **不宣稱能完整阻擋 YouTube 廣告。** YouTube 的廣告不只有網域層面的請求，DNS 過濾無法涵蓋全部。

其他既有限制：只攔截 IPv4 的 UDP DNS；不支援 DNS-over-TCP；不攔截 IPv6 的 DNS；
不顯示廣告攔截次數（無法在不捏造數字的前提下準確統計）。

## 安裝資訊

- 套件名稱：`tw.kuies.block`
- 版本：`versionName 0.4.1`／`versionCode 7`
- 最低需求：Android 9（API 28）；目標 API 37
- 與 v0.4.0 使用**相同的正式簽章**，可直接覆蓋升級；設定、已下載的清單與手動規則都會保留
- 發布檔案：`KuiesBlock-v0.4.1.apk`，校驗檔 `KuiesBlock-v0.4.1.sha256`

## 驗證方式

- 建置：`:app:assembleDebug`、`:app:assembleRelease`（含 R8 與 lintVital）成功，Release 以既有正式簽章簽署。
- 單元測試：588 個測試（67 個測試類別）、0 失敗、1 略過（略過者需要環境變數才會執行）。
- Release APK 的 manifest 與 DEX 已確認不含逐 App 實驗用的除錯元件。
- 實機：設定頁最下方顯示「檢查 App 更新」與「目前版本 v0.4.1」；點「檢查更新」後，因為 GitHub 上的
  最新正式版是 v0.4.0，畫面正確顯示**「目前安裝的版本較新」**；自動更新開關與 8／24 小時選項、
  開機自啟設定、以及 VPN 與規則設定，在覆蓋安裝後都保留。
  **「發現新版本」的對話框與「前往下載」，以及真實行程被系統終止後背景工作的自動恢復，尚未實機驗證。**

## 發布流程備註（不貼進發布頁）

發布 GitHub Release 時，除了上面的正文，發布頁還必須載明下列欄位（於發布當下量測後填入）：

- Release 名稱 `KuiesBlock v0.4.1`，標記為 **Stable（正式版本），不是 Pre-release**
- Release URL 與 tag `v0.4.1`
- 對應的 commit SHA
- APK 檔名、檔案大小與 SHA-256
- 簽章憑證指紋（SHA-256）
- versionName `0.4.1` 與 versionCode `7`

本檔已隨 `Release candidate v0.4.1` commit 納入版本控制；實際的 tag／SHA／大小／雜湊值於發布當下量測填入。
