# KuiesBlock v0.4.0 — 正式版本（Stable）

> 這是正式版本，不是測試版。從本檔開頭到「發布流程備註」之前的內容，就是 GitHub Release 發布頁的正文。

v0.4.0 把廣告攔截的核心從「完全交給伺服器判斷」改為「先在手機上判斷」，並補上規則來源管理、
自己的清單訂閱、手動允許／封鎖，以及第一次使用的引導。

## 這個版本新增什麼

1. **寬鬆／標準／嚴格三級廣告攔截**：自己決定要擋多少，預設是「標準」。
2. **HaGeZi 規則來源管理與手動更新**：看得到目前用的是哪一份清單（包含維護者與授權），也能隨時按「立即更新」。
3. **自訂 HTTPS DNS 訂閱**：可以加入自己的公開清單網址（最多 10 個），也能停用、重新啟用或刪除。
4. **手動允許／封鎖網域**：想放行的網域放進「允許清單」，想擋掉的放進「封鎖清單」，
   可選擇只比對這個網域，或連同所有子網域一起比對。
5. **規則更新失敗時保留最後成功清單**：更新失敗不會把已經生效的規則清掉，畫面會直接說明「仍使用上一次成功的清單」。
6. **首次使用的 VPN 授權及防護教學**：兩頁說明，第一次開啟時自動出現；之後也能從設定頁再看一次。
7. **簡化攔截強度設定**：拿掉「關閉」選項，開與關統一由首頁的按鈕負責，設定頁只負責「要擋多少」。
8. **更清楚的防護生效狀態與操作回饋**：區分「正在啟動」與「尚未生效」，新增規則後會直接在輸入欄下方顯示確認訊息。

## 這個版本的限制（請務必先看）

1. **私人 DNS 設為「指定主機名稱」時，本機規則無法攔截。** 這種情況下系統會自己把查詢送到指定的主機，
   不經過 KuiesBlock，本機規則也就沒有作用。
2. **「防護已啟用」不等於「本機規則正在生效」。** 清單還沒下載完成，或系統私人 DNS 接管解析時，
   連線是正常的，但規則並沒有在作用；畫面會分別顯示實際狀態。
3. **無法與其他一般的 Android VPN 同時運作。** Android 一次只允許一條 VPN 連線，KuiesBlock 不能和別的
   VPN App 並存；偵測到其他 VPN 時只會顯示提示，不會自行把它關掉。
4. **App 自帶的 DoH，或其他繞過系統 DNS 的流量，不保證能被攔截**（例如自帶 DoH 的瀏覽器）。
5. **不宣稱能完整阻擋 YouTube 廣告。** YouTube 的廣告不只有網域層面的請求，DNS 過濾無法涵蓋全部。

其他既有限制：只攔截 IPv4 的 UDP DNS；不支援 DNS-over-TCP；不攔截 IPv6 的 DNS；
不顯示廣告攔截次數（無法在不捏造數字的前提下準確統計）。

## 安裝資訊

- 套件名稱：`tw.kuies.block`
- 版本：`versionName 0.4.0`／`versionCode 6`
- 最低需求：Android 9（API 28）；目標 API 37
- 與 v0.3.0 使用**相同的正式簽章**，可直接覆蓋升級
- 發布檔案：`KuiesBlock-v0.4.0.apk`，校驗檔 `KuiesBlock-v0.4.0.sha256`

## 驗證方式

- 建置：`:app:assembleDebug`、`:app:assembleRelease`（含 R8 與 lintVital）成功，Release 以既有正式簽章簽署。
- 單元測試：482 個測試（52 個測試類別）、0 失敗、1 略過。
- 實機：v0.4.0 的新功能已在一台實機逐項驗證（三級強度、過濾器管理與立即更新、自訂訂閱的完整生命週期、
  手動允許／封鎖、新增後的回饋、首次使用教學的兩頁內容）。
  **全新安裝時的首次顯示，以及教學第二頁的「開啟防護」尚未驗證。**
