# KuiesBlock v0.4.3 — 正式版本（Stable）

> 這是正式版本，不是測試版。從本檔開頭到「發布流程備註」之前的內容，就是 GitHub Release 發布頁的正文。

v0.4.3 新增「個別 App 防護」：預設所有 App 都接受 KuiesBlock DNS 防護，你也可以指定某些 App 完全略過 KuiesBlock VPN，改用系統網路。

## 這個版本新增什麼

1. **個別 App 防護入口**：設定頁新增「個別 App 防護」，顯示目前已排除的 App 數量，點入獨立管理頁。
2. **App 管理頁**：
   - App 搜尋
   - 已安裝 App 清單（圖示、名稱、Package Name）
   - 每個 App 一個防護開關
   - 「全部恢復防護」與確認對話框
3. **預設全部保護**：不需要任何設定，所有 App 都使用 KuiesBlock VPN；只有你關閉的 App 會完全略過。
4. **安全套用**：
   - 使用 Android 官方的 `VpnService.Builder.addDisallowedApplication`。
   - VPN 執行中修改時，會以 250 ms debounce 重建介面並套用最新清單。
   - 新設定建立失敗時，會嘗試回到上一份已成功套用的配置；若仍失敗，VPN 會停止並明確回報，不會假裝新設定已生效。
   - VPN 未啟動時只儲存設定，不會自行啟動 VPN；下次開啟防護時才套用。
5. **持久化與相容**：排除清單以 Package Name 儲存，與廣告攔截模式、過濾來源分開；不影響既有四種模式、自訂來源、自動更新或 DNS-over-HTTPS。

## 這個版本的限制（請務必先看）

1. **只列出具有 launcher entry 的 App。** 沒有桌面圖示的套件不會出現在清單；這是為了避免要求 `QUERY_ALL_PACKAGES`。
2. **排除是 traffic-level。** 被排除的 App 之流量與 DNS 完全不進入 VPN，但仍可能受 Android 私人 DNS 或其他網路政策影響。
3. **不是逐查詢的 App 歸因。** 本版只控制哪些 App 的流量進入 VPN，不會為不同 App 套用不同 DNS 規則或個別攔截強度。
4. **修改設定時 VPN 會短暫重建。** 快速連續變更由 250 ms debounce 合併；重建期間防護可能短暫重新啟動。
5. **失敗回退的完整流程仍為 `INCONCLUSIVE`。** 平台拒絕 `establish()`、PackageManager 查詢失敗的 UI、快速切換 debounce、真正重新開機後的保留，以及第三方 App 自身 DNS 流量，尚未有實機完整證據。
6. **已解除安裝的 App 會保留設定。** 平台可能接受或忽略不存在的 Package Name；重新安裝相同 Package Name 後，設定可再次生效。
7. **v0.4.2 與之前版本的所有已知限制繼續適用**：私人 DNS 指定主機名稱時本機規則無法介入；「防護已啟用」不等於本機規則生效；無法與其他一般 VPN 並存；App 自帶 DoH 或繞過系統 DNS 的流量不保證攔截；不宣稱完整阻擋 YouTube 廣告；只攔截 IPv4 UDP DNS；自動更新與開機自啟為盡力而為；App 更新檢查不自動安裝。

## 安裝資訊

- 套件名稱：`tw.kuies.block`
- 版本：`versionName 0.4.3`／`versionCode 9`
- 最低需求：Android 9（API 28）；目標 API 37
- 與 v0.4.2 使用相同的正式簽章，可直接覆蓋升級；設定與已下載的清單會保留
- 發布檔案：`KuiesBlock-v0.4.3.apk`，校驗檔 `KuiesBlock-v0.4.3.sha256`

## 驗證方式

- 建置：`:app:assembleDebug`、`:app:assembleRelease`（含 R8 與 lintVital）成功，Release 以既有正式簽章簽署。
- 單元測試：606 個測試（70 個測試類別）、0 失敗、1 略過（略過者需要環境變數才會執行）。
- 實機：管理頁、搜尋、圖示／名稱／Package Name、開關、已排除數量、全部恢復確認流程可操作；Spotify UID 10339 在 VPN UID 集合中被移除並恢復，VPN 全程 `VALIDATED`；程序重啟後設定保留；VPN 明確停止時切換只儲存、不自行啟動，下次啟動套用；全部恢復清空清單並恢復 UID 覆蓋。
- 上述 `INCONCLUSIVE` 邊界不列為實機 PASS。
