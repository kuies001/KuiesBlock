# KuiesBlock v0.4.41 — 正式版本（Stable）

> 這是正式版本，不是測試版。從本檔開頭到「發布流程備註」之前的內容，就是 GitHub Release 發布頁的正文。

v0.4.41 把「檢查更新」升級為 App 內下載與系統安裝：發現新的正式版本後，KuiesBlock 可以直接下載官方 APK、驗證檔案，再交給 Android 系統安裝器完成更新，不需要自行前往 GitHub 下載頁。

## 這個版本新增什麼

1. **App 內下載更新**
   - 發現新版本後顯示版本與更新說明，按「下載並更新」才開始下載。
   - 下載時顯示「正在下載更新」、百分比與「取消下載」。
   - 下載完成後顯示「正在驗證更新檔」，驗證通過才開啟系統安裝器。
   - 下載失敗顯示簡短原因與「重試」；取消或失敗會清除未完成的暫存檔。
2. **APK 安全驗證**
   - SHA-256：優先使用 GitHub Release Asset 提供的 digest；沒有時改用同一 Release 的 `.sha256` 校驗檔。兩者都無法取得就不允許安裝。
   - 套件名稱必須是 `tw.kuies.block`。
   - APK `versionName` 必須與 Release tag 的版本一致，`versionCode` 必須高於目前安裝版本，不允許降版。
   - 使用 Android 平台的 `GET_SIGNING_CERTIFICATES` 解析並驗證 APK 簽章，再比對憑證 SHA-256：
     `b6f5ccd5b3c8497e8b095db2c653c0dfe5b1c6e9b84b0f67307aad501af3235c`
   - 下載網址只接受 `https://github.com/kuies001/KuiesBlock/releases/download/<tag>/<name>`，轉址只允許 GitHub 官方 Release CDN。
3. **Android 系統安裝器**
   - APK 只下載到 App 私有快取，透過 FileProvider 以 `application/vnd.android.package-archive` 交給系統安裝器。
   - 只授予暫時性的 URI 讀取權限，並宣告 `REQUEST_INSTALL_PACKAGES`。
   - 尚未允許安裝未知來源 App 時，會顯示提示並導向系統設定；返回且授權後，會繼續開啟同一份已驗證 APK。
   - 不使用 root、Accessibility 或靜默安裝，也不繞過 Android 安裝確認。
4. **簽章不同的處理**
   - 若目前安裝的是 Debug 簽章版本，而下載的是正式簽章 APK，會顯示無法直接覆蓋的說明。
   - 不會要求清除資料，也不會自動解除安裝；更新流程不改動任何設定。
5. **版本比較**
   - 版本以三段數字逐段比較，`0.4.4 < 0.4.41 < 0.4.42 < 0.5.0`，不把版本號當成浮點數。

## 這個版本的限制（請務必先看）

1. **本版只新增更新通道，沒有改變 DNS／VPN／過濾核心。** 四種廣告攔截模式、自訂來源、規則下載與解析、WorkManager 自動更新、個別 App 防護、VPN 排除與重建、開機自動啟動、DoH 與私人 DNS 都維持原行為。
2. **更新流程不會自動下載或自動安裝。** 只有使用者按下「下載並更新」才會開始，最後仍由 Android 系統安裝確認畫面決定。
3. **需要目前安裝版本使用正式簽章。** Debug 簽章版本無法直接覆蓋成正式版本；這是 Android 的簽章規則，不是本版繞過或改寫的對象。
4. **實機下載與安裝仍為 `INCONCLUSIVE`。** 本輪沒有執行 Emulator、ADB 或實機安裝測試；下載進度、取消、未知來源授權返回、系統安裝器覆蓋安裝與資料保留，需由使用者實機確認。
5. **v0.4.4 與之前版本的所有已知限制繼續適用**：私人 DNS 指定主機名稱時本機規則無法介入；「防護已啟用」不等於本機規則生效；無法與其他一般 VPN 並存；App 自帶 DoH 或繞過系統 DNS 的流量不保證攔截；不宣稱完整阻擋 YouTube 廣告；只攔截 IPv4 UDP DNS；自動更新與開機自啟為盡力而為。

## 安裝資訊

- 套件名稱：`tw.kuies.block`
- 版本：`versionName 0.4.41`／`versionCode 11`
- 最低需求：Android 9（API 28）；目標 API 37
- 與 v0.4.4 使用相同的正式簽章，可直接覆蓋升級；設定與已下載的清單會保留
- 發布檔案：`KuiesBlock-v0.4.41.apk`（3,020,158 bytes／約 2.88 MiB）
- 校驗檔：`KuiesBlock-v0.4.41.sha256`
- SHA-256：`e6b372f5b3003eea42a9f3667c980eacaac8a17a120a8cabc168c4c8d91c79b1`

- 建置：`:app:assembleDebug`、`:app:assembleRelease`（含 R8 與 lintVital）成功，Release 以既有正式簽章簽署。
- 單元測試：620 個測試（71 個測試類別）、0 失敗、1 略過（略過者需要環境變數才會執行）。
- 簽章憑證 SHA-256：`b6f5ccd5b3c8497e8b095db2c653c0dfe5b1c6e9b84b0f67307aad501af3235c`
- 已用 `apksigner verify --print-certs` 確認發布 APK 的簽章指紋，與先前正式 v0.4.4 APK 相同。
- 實機下載、安裝授權、系統安裝器與資料保留：`INCONCLUSIVE`，本輪未執行。
