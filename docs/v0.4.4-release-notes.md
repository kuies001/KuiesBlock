# KuiesBlock v0.4.4 — 正式版本（Stable）

> 這是正式版本，不是測試版。從本檔開頭到「發布流程備註」之前的內容，就是 GitHub Release 發布頁的正文。

v0.4.4 是 UI 整理版本：首頁與「App 個別防護」入口改版，設定頁則移除重複資訊與一般使用者不需要的技術細節。DNS、VPN、過濾規則下載與解析等核心行為沒有改變。

## 這個版本新增什麼

1. **首頁直接進入 App 個別防護**：首頁新增「App 個別設定」入口，並顯示目前已排除的 App 數量；設定頁不再重複同一個入口。
2. **App 個別防護頁更完整**：
   - 新增「全部 App」與「已排除」兩個分頁，可直接查看哪些 App 略過 KuiesBlock VPN。
   - 保留搜尋、App 圖示／名稱／Package Name、每個 App 的防護開關。
   - 新增右上角「更多選項」，集中「重新過濾所有 App」與確認流程。
   - 已解除安裝但仍在排除清單中的項目，仍會出現在「已排除」分頁，方便恢復。
3. **過濾器管理精簡**：
   - 每個生效來源只顯示一次名稱；標準模式只會看到 HaGeZi Multi NORMAL，自訂模式則列出已選來源。
   - 顯示目前 Snapshot 的實際生效規則數（含千分位），未生效時顯示「尚未生效」。
   - 最後更新只採用真正成功的更新時間，不會把失敗時間當成更新成功。
   - 尚未下載顯示「尚未下載」；更新失敗會簡短顯示原因，並註明仍使用上一次成功的清單。
   - 保留「立即更新」、自動更新開關與每 8／24 小時週期。
   - 維護者與 GPL-3.0 授權集中為卡片底部的簡潔來源資訊。
4. **移除連線診斷介面**：設定頁不再提供「執行 DNS 診斷」、診斷結果或 DoH／TLS 技術資訊；底層 DNS 診斷與錯誤處理程式仍保留。
5. **關於與檢查更新合併**：單一「關於」卡片顯示「目前版本：v0.4.4」與「檢查更新」，保留 GitHub Stable Release 檢查、更新說明、前往下載與防重複點擊；不會自動下載或安裝 APK。
6. **設定頁文案簡化**：移除產品標語、重複版本、維護者介紹、用途長文與重複狀態標籤，保留必要的隱私、授權與操作結果提示。

## 這個版本的限制（請務必先看）

1. **本版只調整 UI 與必要的畫面狀態整合。** 四種廣告攔截模式、自訂過濾來源、規則下載與解析、WorkManager 自動更新、個別 App 防護、VPN 排除與重建、開機自動啟動、DoH 端點與私人 DNS 都沒有改變。
2. **連線診斷只剩底層程式。** 設定頁已沒有手動診斷入口；防護失敗時仍會顯示必要的錯誤資訊。
3. **「檢查更新」只會開啟 GitHub Release 頁面。** 不會自動下載或安裝 APK。
4. **v0.4.3 與之前版本的所有已知限制繼續適用**：私人 DNS 指定主機名稱時本機規則無法介入；「防護已啟用」不等於本機規則生效；無法與其他一般 VPN 並存；App 自帶 DoH 或繞過系統 DNS 的流量不保證攔截；不宣稱完整阻擋 YouTube 廣告；只攔截 IPv4 UDP DNS；自動更新與開機自啟為盡力而為。

- APK 檔名、檔案大小與 SHA-256
- 簽章憑證指紋（SHA-256）
- versionName `0.4.4` 與 versionCode `10`
